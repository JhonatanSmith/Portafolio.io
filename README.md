# Jhonatan Smith Portfolio

Premium single-page portfolio built with Next.js, TypeScript, Tailwind CSS, and Framer Motion.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

## Build static export

```bash
npm run build
```

The static output is generated in `out/`.

# Portfolio Refactor Master Prompt for GitHub Copilot

Use this document as the single source of truth to rebuild my personal portfolio website from scratch as a premium, production-ready, highly polished portfolio for a Data Engineer / Data Scientist / GenAI Engineer.

Your role is not to make minor edits. Your role is to perform a full professional refactor and redesign of the current static portfolio into a modern, elegant, responsive, animated, premium-quality portfolio website that looks like a top-tier tech product website rather than a traditional CV website.

The final result must feel intentional, minimal, sophisticated, modern, technically credible, visually memorable, and suitable for an engineer working in data engineering, machine learning, cloud, analytics, and generative AI.

---

## 1. Project Objective

Rebuild my existing personal portfolio website into a highly professional portfolio that:

* Presents me as a serious technical professional.
* Highlights my profile as a Data Engineer, Data Scientist, and GenAI Engineer.
* Feels visually premium and modern.
* Uses a landing-page style layout with smooth scrolling instead of tab-based content switching.
* Is fully responsive and mobile-first.
* Includes tasteful animations and micro-interactions.
* Uses a strong visual system with modern color harmony.
* Keeps the experience fast, clean, accessible, and easy to maintain.
* Is deployable as a static site through GitHub Pages.

This is a redesign and refactor, not a patch.

## 4. Mandatory Tech Stack

Build the project using the following stack:

* **Next.js** (latest stable version, App Router preferred if suitable)
* **TypeScript**
* **Tailwind CSS**
* **Framer Motion** for animations
* **Lucide React** for icons
* **shadcn/ui** only if needed for clean reusable UI primitives

The output must be compatible with **static export** so it can be deployed to **GitHub Pages**.

Implementation requirements:

* Structure the project cleanly and professionally.
* Avoid unnecessary complexity.
* Avoid overengineering.
* Use reusable components.
* Prefer clean composition over monolithic files.
* Optimize for maintainability.

## 5. Deployment Constraint

The final project must be buildable and deployable as a static site to GitHub Pages.

Take this into account when implementing:

* Prefer static content and local assets.
* Avoid server-only features.
* Avoid API dependencies unless they are purely optional and safely ignorable.
* Make sure routing and assets work correctly in static export mode.

## 6. Design Philosophy

The design must be guided by these principles:

1. **Premium simplicity**

   * clean layouts
   * strong spacing
   * minimal clutter
   * every section feels intentional

2. **Modern technical credibility**

   * looks like the site of a serious engineer
   * not flashy for the sake of being flashy
   * visually strong but restrained

3. **Narrative flow**

   * the page should read like a professional story
   * the user should scroll naturally through the content
   * information hierarchy must be excellent

4. **Motion with discipline**

   * smooth, elegant animations
   * no gimmicks
   * no annoying repeated motion
   * animation should reinforce quality, not distract

5. **Visual coherence**

   * one solid design language
   * one coherent palette
   * one typography system
   * consistent component behavior

## 9. Visual Style Requirements

### Color System

Use a dark premium palette with refined contrast.

The palette should feel modern and elegant, inspired by data, cloud, AI, and software product design.

Recommended direction:

* deep charcoal / near-black base
* soft off-white text
* muted secondary text
* one primary accent color
* one optional complementary accent for gradients or highlights

Potential accent directions:

* indigo + cyan
* blue + violet
* slate + electric blue

Avoid:

* harsh yellow as the main visual identity
* oversaturated neon everywhere
* rainbow palettes
* low-contrast gray-on-gray combinations

The website should look premium on both laptop and mobile.

### Typography

Use modern, professional typography.
Recommended font directions:

* Inter
* Space Grotesk
* Manrope

Use a clear hierarchy:

* strong hero headline
* clean section headings
* readable body text
* restrained use of uppercase labels

Typography must feel high-end and product-oriented.

### Surfaces and Components

Use:

* soft borders
* subtle shadows
* layered depth
* restrained glow only where justified
* rounded corners, but not cartoonishly large
* clean card treatments

Avoid:

* old-fashioned gradients everywhere
* thick borders everywhere
* noisy textures
* excessive glassmorphism

---

## 10. Motion and Animation Requirements

Animations must be elegant, smooth, and restrained.
Use **Framer Motion**.

Allowed animation patterns:

* fade in + slight upward motion on section reveal
* staggered card reveals
* subtle hover lift on cards
* smooth button hover states
* soft image zoom on hover where appropriate
* animated underline or indicator in navigation
* gentle background glow movement if subtle

Avoid:

* spinning elements
* exaggerated parallax
* bouncing effects
* typewriter effects unless extremely tasteful
* any animation that hurts readability or feels gimmicky

Animation goals:

* premium feel
* polish
* perceived quality
* better hierarchy
